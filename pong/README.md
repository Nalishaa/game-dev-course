# Pong

A recreation of the classic Pong arcade game, developed in Lua as part of [CS50's Introduction to Game Development]

## About

This project recreates the basic mechanics of Pong, a two-player arcade game where players control paddles to hit a ball back and forth. The objective is to score points by getting the ball past the opponent's paddle.

## Technologies

- Lua
- LÖVE (Love2D) framework

## What I Learned

- Game loops and frame-based updates
- Keyboard input and paddle movement
- Ball physics and collision detection
- Scoring and game state management
